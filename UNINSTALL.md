# Uninstall Drawstate

1. Open Drawstate Settings and turn off **Start automatically at login**.
2. Choose **Quit Drawstate** from its menu-bar panel.
3. Move `Drawstate.app` from Applications to Trash.

Optional preference cleanup:

```sh
defaults delete com.kiankonradtajbakhsh.drawstate
```

Drawstate creates no administrator helper, system extension, kernel extension, cloud account, or network service.
