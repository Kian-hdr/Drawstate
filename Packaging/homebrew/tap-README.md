# Homebrew Tap for Drawstate

This is the official Homebrew tap for [Drawstate](https://github.com/Kian-hdr/Drawstate), a native macOS menu-bar utility for live power and battery telemetry.

Install from this official tap:

```sh
brew tap Kian-hdr/drawstate
brew install --cask drawstate
```

The cask is updated from Drawstate's signed release workflow. Each cask version points to the corresponding notarized [GitHub Release](https://github.com/Kian-hdr/Drawstate/releases) and verifies its SHA-256 checksum.
